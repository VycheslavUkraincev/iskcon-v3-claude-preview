# iskcon-v3-claude-preview

Превью **макетов главной страницы** ІСККОН Чернівці, вариант Claude. **Это не живой сайт.** Живой сайт — https://iskcon.cv.ua/.

- `mockup/` — побайтная копия папки `mockup/` из `VycheslavUkraincev/iskcon-v3`, ветка `design/claude`, коммит `8ff690a`: главная, `courses/`, `food/`, `donation/`, `404.html`; светлая тема и тема «Шьяма» (переключатель в шапке или `?theme=light|shyama`), в «Шьяме» на главной — фото вівтаря в лотосе.
- `mockup-style3/` — копия папки `mockup-style3/` из того же коммита, без `REPORT.md`: стиль 3 «Жива картина» (только главная; её меню ведёт на страницы `mockup/`).
- Между тремя вариантами можно переходить по полосе над шапкой.
- `assets/` — только файлы, на которые ссылаются макеты (фото, логотипы, шрифт Onest, словарь i18n, `next-sunday.js`, GSAP), скопированы из той же ветки без изменений.
- Корневой `index.html` — список трёх вариантов главной и остальных страниц макета.
- Индексация запрещена: `robots.txt` (`Disallow: /`) и `meta robots noindex` на страницах.
- Ссылки между страницами макета работают. Страница 404 макета открывается по прямому адресу `mockup/404.html`.
- Платёжные данные (WayForPay, QR, IBAN, Monobank) — те же, что на живом сайте: это рабочие реквизиты, превью не тестовое.
