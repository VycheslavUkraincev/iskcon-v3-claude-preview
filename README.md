# iskcon-v3-claude-preview

Превью **макета главной страницы** ІСККОН Чернівці, вариант Claude. **Это не живой сайт.** Живой сайт — https://iskcon.cv.ua/.

- Макет: `mockup/` — побайтная копия папки `mockup/` из `VycheslavUkraincev/iskcon-v3`, ветка `design/claude`, коммит `68ed4d5`.
- `assets/` — только файлы, на которые ссылается макет (фото, логотипы, словарь i18n, `next-sunday.js`, GSAP), скопированы из той же ветки без изменений.
- Корневой `index.html` только переводит на `mockup/`.
- Индексация запрещена: `robots.txt` (`Disallow: /`) и `meta robots noindex` на страницах.
- Ссылки на «Навчання», «Їжа життя», «Пожертви» в превью ведут на несуществующие страницы (404): в превью только главная.
